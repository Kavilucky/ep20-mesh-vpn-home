# ep20-mesh-vpn-home: приватный Mesh-VPN домой без белого IP

Набор из 20-го выпуска канала [@ByteAutomate_AI](https://t.me/ByteAutomate_AI): свой координатор **Headscale** в Docker Compose и скрипты подключения устройств через клиент **Tailscale** (WireGuard). Доступ к домашним файлам и панелям без проброса портов на роутере и без абонентской платы.

```bash
git clone https://github.com/Kavilucky/ep20-mesh-vpn-home
cd ep20-mesh-vpn-home
docker compose up -d
```

## Архитектура
```
телефон / ноутбук (любая сеть, мобильный интернет, коворкинг)
        │  WireGuard P2P-туннель напрямую между устройствами
        │  (если прямое соединение не строится: реле DERP, задержка выше)
        ▼
домашний сервер: Headscale (координатор, порт 8080 во внутренней сети) + ваши сервисы
```
Порты на роутере не открываются. Headscale выдаёт устройствам адреса из диапазона 100.64.0.0/10 (адрес `100.64.0.1` в файлах пример, подставьте свой).

## Файлы
| Файл | Назначение |
|---|---|
| `docker-compose.yml` | Headscale для домашнего сервера |
| `config.yaml` | минимальная конфигурация Headscale (черновик, сверьте с актуальной документацией проекта) |
| `connect_linux.sh` | подключение Linux-устройства: `sh connect_linux.sh https://ваш-сервер` |
| `connect_windows.bat` | подключение Windows-устройства |
| `Инструкция.txt` | пошаговая инструкция из архива подписчиков |

## Резервная копия по правилу 3-2-1
Ключи Headscale, `config.yaml` и папку `data` копируйте по схеме **3-2-1**: три копии, два разных носителя, одна вне дома. Копия на том же диске второй копией не считается. Оригиналы не удаляйте, пока копия не проверена (распакуйте и убедитесь, что Headscale стартует из неё).

## Честные ограничения
- У мобильных операторов бывает жёсткий симметричный NAT: прямое соединение не строится, трафик идёт через реле DERP с задержкой. Условия проекта проверяйте на сайте.
- Пинг 10–15 мс из ролика сценарный пример, не замер.
- Не открывайте порт Headscale в интернет без пароля и HTTPS.
- Конфигурация-черновик: сверяйте имена параметров с документацией вашей версии Headscale. Набор не проверялся на чужом железе.
